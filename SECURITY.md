# Säkerhetsbrister

Rapportera säkerhetsbrister privat via [GitHubs säkerhetsformulär](https://github.com/Visegue/Botton-Shelf/security/advisories/new). Ange berörd version eller URL, reproduktionssteg och möjlig påverkan med syntetiska exempel.

Lägg inte hemligheter, sessionsuppgifter, verkliga inventeringsdata eller angreppsdetaljer i publika issues eller PR:er. Vanliga fel och funktionsförslag hör hemma i GitHub Issues.
